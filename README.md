---

## What is Nova?

Nova is a Windows-based personal AI assistant designed to understand natural-language
commands, reason about complex goals, and interact with the user's computer.

The long-term goal is not simply to build another chatbot.

Nova is being designed as an agentic computer-control system:

```text
Understand → Plan → Route → Execute → Verify → Recover
```
